[Instrucciones de Ejecución]

-----------------------------------------------------------------------------------------------------------
Para lograr una exitosa ejecución del programa, en la terminal, se deben tener en cuenta los
siguientes comandos:
1-"make": Este comando compila el programa.

2-"make run": Ejecuta el programa.

3-"make clean": Este comando elimina el programa que se compiló de su computadora para que no ocupe espacio.
